# RotomBot
Autonomous Drone Project

My Contribution mainly includes:

• Defined project requirements, verification & validation methods, and achieved 100% satisfaction from related
stakeholders.
• Implemented ROS nodes for autonomous flight (hover, waypoint navigation, obstacle avoidance) using VIO fusion
from Intel Realsense T265 and VICON. Deployed SmolVLM-2.2B from a remote server with custom prompt;
evaluated SmolVLM-256/500M and Moondream2-0.5B/2B..
• Used Laplacian and Canny edge detectors for crack detection on camera feed; built a SQL database and Flask
API to relay images and VLM outputs.
